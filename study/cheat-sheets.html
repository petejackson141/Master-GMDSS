Call signs

Call signs and identification tell you the type of station. A call sign is made of letters and numbers. The first two characters are the country (two letters, a letter and a number, or a number and a letter); Israel is 4X or 4Y.

Country codeLifeboat digits

Coast station

4XO

Country code 4Y/4X + XXX digits (other than 1 or 0) + X additional letter. Example 4XO (RCC Haifa)

Ship

4XBG8

Country code 4Y/4X + XX additional letters + X digit. Example 4XBG8

Lifeboat

4XBG857

Mothership identification + XX additional digits. Example 4XBG857

Airplane

4XGSK

Country code 4Y/4X + XXX additional letters. Example 4XGSK

Airplane lifeboat

4XGSK6

Aircraft identification + X additional digit. Example 4XGSK6

The digits 1 and 0 are never used, because they are easily confused with the letters I and O. So in a call sign, that shape is always the letter I or O.

Lifeboats take their parent's call sign and add digits: ship 4XBG8 → lifeboat 4XBG857; aircraft 4XGSK → aircraft lifeboat 4XGSK6.
